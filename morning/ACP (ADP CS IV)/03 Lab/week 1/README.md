# Week 1: Introduction to IDE & Java Components

This directory contains the lab tasks for Week 1.

## Setup Instructions

### 1. Configure JDK
Ensure you have Java JDK 17 (or higher) installed. You can check this by running:
```bash
java -version
javac -version
```

### 2. Configure Environment Variables
Make sure the `JAVA_HOME` variable points to your JDK installation directory, and your `%JAVA_HOME%\bin` is added to your system `PATH`.

---

## Lab Tasks Overview

1. **HelloWorld.java**: A basic Java program that prints "Hello, World!" to the console.
2. **ModifiedHelloWorld.java**: An execution showing variables, comments, custom messages, and basic syntax rules (e.g. standard output, formatting).

---

## How to Compile & Run

Using Command Prompt / PowerShell:
```bash
# Compile the files
javac HelloWorld.java ModifiedHelloWorld.java

# Run the HelloWorld program
java HelloWorld

# Run the ModifiedHelloWorld program
java ModifiedHelloWorld
```
